# 🚀 Personal Portfolio – NJIT Business/Data Analyst

## Overview
This project is a **high-performance personal portfolio website** built to position me as a **Business/Data Analyst candidate** targeting Summer 2026 internships.

The goal is simple:
> Communicate value to recruiters in under 10 seconds and convert attention into action.

This site highlights:
- My transition from **Commerce (India) → NJIT (USA)**
- My ability to **combine business thinking with technical execution**
- A **case-study-driven approach** instead of generic portfolios

---

## 🎯 Target Audience
- Recruiters from firms like **JPMorgan, Deloitte, Barclays**
- Hiring managers looking for **analytical, business-minded candidates**
- Teams that value **data-driven thinking + execution ability**

---

## 🧠 Project Choice (Why This Stack?)

### Stack:
- HTML
- Tailwind CSS (CDN)
- Lightweight JavaScript

### Rationale:
This project intentionally avoids complex frameworks.

**Why?**
- ⚡ **Speed**: Instant load time = better recruiter retention
- 🔍 **SEO**: Static HTML is easily indexed
- 🧼 **Simplicity**: No build tools, no friction
- 🚀 **Deployment**: Works instantly with GitHub Pages
- 📱 **Responsiveness**: Tailwind enables fast mobile-first design

> This is not an engineering-heavy app.  
> This is a **conversion-focused product**.
